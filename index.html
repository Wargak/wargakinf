about

A developer who started with curiosity, not a classroom

Wargak Nhial — Addis Ababa / remote

My path into technology didn't start in a lecture hall it started with taking things apart to understand how they worked, and a stubborn need to fix what was broken. That same instinct eventually led me to code: the first time a script I wrote actually did something, I was hooked.

Since then I've taught myself to build across the stack from responsive front-end interfaces to the backend logic and APIs that power them while also repairing and troubleshooting the mobile hardware that so many people depend on every day. I care about software that respects the person using it: fast, clear, and built for real conditions, not just a perfect demo.

My design philosophy is simple: clarity beats cleverness. A good interface should feel obvious in hindsight. My goal as a developer is to keep building tools that are genuinely useful to the communities I come from — and to keep getting better at the craft, one project at a time.
